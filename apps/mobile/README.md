# CommonTable Mobile App

**Status:** DEFERRED TO PHASE 2

This folder is a placeholder for the React Native + Expo mobile application, which will be implemented in Phase 2.

## Planned Tech Stack (Phase 2)

- React Native + Expo
- Expo Router (file-based navigation)
- WatermelonDB (offline storage)
- Material Design components (or responsive web in WebView)

## V1 Scope

For V1, we're building a mobile-responsive PWA using Next.js + Material UI. The web app works on mobile browsers and can be installed as a PWA on iOS and Android.
